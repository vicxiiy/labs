## Задание 2. Имена, объекты и сравнение
```
#данные
a = 1000
b = a
c = int("1000")

print("Типы:", type(a), type(b), type(c))
print("Идентификаторы:", id(a), id(b), id(c))
print("a == b:", a == b)
print("a is b:", a is b)
print("a == c:", a == c)
print("a is c:", a is c)
```
Сделали прогноз:
```
a == b: True
a is b: True
a == c: True
a is c: False
```
Полученные результаты:
```
Типы: <class 'int'> <class 'int'> <class 'int'>
Идентификаторы: 2211633215056 2211633215056 2211636076624
a == b: True
a is b: True
a == c: True
a is c: False
```
Фактический результат совпал с прогнозом: `a` и `b` – это два имя, указывающие на один и тот же объект в памяти. Имя `c` – ссылка на другой объект, другой id, у которого просто совпадает значение.

__1.__	Связи между именами и объектами в виде текстовой схемы:
```
a ─┐
   ├──> [объект `int`, значение=1000, id один(2875255731792)]
b ─┘
c ────> [объект `int`, значение=1000, id второй(2875258593360)]
```

__2.__	Равенство значений – сравнивает содержимое объектов, отвечает на вопрос «одинаковы ли значения?». Идентичность объектов – сравнивает адреса объектов в памяти, отвечает на вопрос «это один и тот же объект или два разных объекта с одинаковым содержимым?»

__3.__	Изменение `c` на `None` и проверка:
```
c = None
print("c is None:", c is None)
```
Результат:
`c is None: True`

Так как оператор == вызывает метод `__eq__`, который можно переопределить в пользовательском классе (и он может вернуть True даже для объекта, не являющегося None), то корректной проверкой на None будет являться is, потому что она сравнивает идентичность объектов напрямую и не зависит от того, как в классе реализован `__eq__`. 

__4.__	Выполнили следующий фрагмент:
```
first = "python"
second = "py" + "thon"

print(first == second)
print(first is second)
```

Оба сравнения дают `True`. Строку `"python"`, написанную прямо в коде, Python хранит в одном экземпляре и переиспользует её при повторе. Вторая строка склеена из кусочков прямо в коде `("py" + "thon")`, и Python считает результат заранее, до запуска программы. Получается та же строка `"python"`, поэтому он снова использует уже готовый объект вместо нового. Такое интернирование строк и свёртка констант являются деталью реализации CPython, поэтому логика программы не должна на это опираться: для сравнения строк по значению нужно использовать `==`.

__5.__	`==` используется для сравнения значений, когда нужно узнать, одинаковы ли данные - числа, строки, списки и т.д. `is` используется только для сравнения идентичности объектов - это один и тот же объект в памяти или два разных объекта с одинаковым значением.

### Контрольные вопросы:

__1.__	Инструкция `b = a` не создаёт копию объекта - она создаёт новую ссылку `b`, которая указывает на тот же объект, что и a. Это подтверждается совпадением `id(a)` и `id(b)`.

__2.__	`type()` возвращает класс объекта, показывает, к какому виду данных он относится. `id()` возвращает уникальный идентификатор объекта, который в CPython фактически соответствует адресу объекта в памяти на время его существования.

__3.__	`None` - единственный объект своего типа, существующий в программе в одном экземпляре, поэтому сравнивать его по идентичности через `is` корректно, быстрее и надёжно. Числа и строки, наоборот, могут существовать как разные объекты с одинаковым значением, поэтому для них важно именно значение, а не факт, что это буквально один и тот же объект в памяти.

Компьютер хранит дробные числа в двоичном виде, а не в десятичном. __Правило безопасного сравнения:__ дробные числа нельзя сравнивать через `==`. Нужно проверять, что они достаточно близки друг к другу - например, через `math.isclose(a, b)`.

### Контрольные вопросы:

__1.__	Оператор `/` в Python 3 является оператором «истинного» деления: результат деления двух целых чисел в общем случае нецелый, а `int` дробную часть хранить не может. __Причина ошибки в №8.__ Тип str в Python - неизменяемый. Это значит, что после того как объект строки создан, его нельзя изменить: нельзя заменить, удалить или добавить отдельный символ внутри уже существующего объекта. 

### Контрольные вопросы:

__1.__	`len()` для строки считает количество символов Unicode, а `len()` для результата `.encode("utf-8")` считает количество байтов, так как `encode()` возвращает объект `bytes` - представление текста по правилам кодировки. UTF-8 - кодировка переменной длины, где символ занимает от 1 до 4 байт в зависимости от кодовой позиции. Поэтому длина строки и байтового представления совпадают только для однобайтовых символов, а для остальных байтовая длина больше.

__2.__	`start` - индекс, с которого начинается срез (включительно). `stop` - индекс, на котором срез заканчивается (символ с этим индексом в результат не входит). `step` - шаг, с которым берутся символы: положительное значение задаёт направление вперёд и интервал между выбираемыми символами, отрицательное - направление в обратную сторону. Любой из параметров можно опустить, тогда используется значение по умолчанию: начало или конец строки (в зависимости от знака шага) и шаг, равный 1.

__3.__	Неизменяемость означает, что после создания объекта строки его внутреннее содержимое нельзя изменить. Методы вроде `.upper()` и операции конкатенации не изменяют исходный объект - они создают и возвращают новый объект строки с нужным содержимым, а исходная строка остаётся в памяти без изменений. 

## Задание 5. Информационная карточка вычислительного эксперимента
```

Программа запрашивает у пользователя сведения об исследователе и об

комплексного коэффициента), выполняет ряд простых вычислений без
использования условных операторов и циклов, и выводит аккуратно
оформленную карточку с результатами, а также диагностическую строку
с типами всех введённых значений.
"""

# Ввод данных
researcher_name = input("Введите имя исследователя: ")
experiment_name = input("Введите название эксперимента: ")
runs_count = int(input("Введите количество выполненных запусков: "))
run_duration = float(input("Введите длительность одного запуска в секундах: "))
coeff_real = float(input("Введите действительную часть коэффициента: "))
coeff_imag = float(input("Введите мнимую часть коэффициента: "))
```

__3.	Путь программы от исходного файла до выполнения:__

__Исходный файл:__ текст программы, записанный в виде обычных символов.
__Разбор исходного текста:__ интерпретатор делит текст на токены (имена, числа, операторы, скобки), а парсер проверяет, что они образуют корректную программу, и сразу строит из них AST.
__AST:__ абстрактное синтаксическое дерево, в котором остаётся только смысл инструкций: присваивания, вызовы функций, арифметические операции.
__Компиляция в байткод:__ по AST компилятор создаёт низкоуровневые команды для виртуальной машины Python (при этом, например, выражение `4 * 2` может быть вычислено заранее).
__Выполнение виртуальной машиной CPython:__ команды байткода выполняются по очереди: создаются объекты, вызываются функции, имена связываются с объектами, и программа выводит результат.

__4.__	`input()` всегда возвращает объект типа `str`, независимо от того, что ввёл пользователь. Строка и число - это объекты разных типов, и операторы ведут себя с ними по-разному: например, `*` для строк означает повторение, а не умножение. Без явного преобразования арифметическое выражение с такой строкой либо привело бы к ошибке TypeError, либо дало бы неожиданный результат. Поэтому `int()` и `float()` создают новый объект нужного числового типа, с которым арифметические операторы работают корректно.

### Контрольный вопрос:

При повторном присваивании нового значения уже существующему имени сам старый объект не меняется, а создаётся новый объект с новым значением, имя отвязывается от старого объекта и привязывается к новому. Если на старый объект больше никто не ссылается, он становится недостижимым. То есть меняется не объект, а связь между именем и объектом - имя начинает указывать на другой объект в памяти. Это верно для всех имён в программе: переприсваивание создаёт новую привязку к новому объекту, а не изменяет старый.

## Вывод:

В результате выполнения лабораторной работы можно выделить три особенности Python:

__1.__ Целые числа в Python не переполняются. Выражение `2 ** 1000` вычисляется без ошибок и даёт точное число из 302 цифр, хотя в других языках  уже `2 ** 64` не поместилось бы в стандартный целочисленный тип. Python хранит число как последовательность «цифр» по 30 бит и автоматически увеличивается по мере роста значения. 

__2.__ `0.1 + 0.2 != 0.3`. Причина заключается в разрыве между десятичным мышлением человека и двоичным хранением чисел с конечной точностью, из-за чего сравнение через `==` заменяется на `math.isclose()`.

__3.__ Строки в Python неизменяемы. Попытка изменить символ присваиванием по индексу вызывает `TypeError: 'str' object does not support item assignment`. Методы вроде `.upper()` тоже не трогают исходную строку, а создают и возвращают новый объект. Поэтому «изменение» строки на деле означает создание нового объекта и перепривязку имени к нему.
